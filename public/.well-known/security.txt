# `Expires` is a hard expiry: RFC 9116 section 2.5.5 requires the field and says

# none — it advertises a channel researchers are told to disregard.
# `make lint-security-txt` fails once FEWER than 60 days remain, while there is
# still time to review and merge a refresh, so this can never go stale silently.
# Fix a failing gate by BUMPING the date and re-confirming the contacts below
# still reach a human — never by lowering the threshold in
# scripts/ci/check-security-txt.sh.
